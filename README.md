# Network Sniffer

A Python-based Network Sniffer designed to capture and analyze network packets in real time.

## Features

- Real-time network packet capturing
- Network traffic inspection
- Packet analysis
- Lightweight Python implementation

## Requirements

- Python 3
- Required Python libraries (see installation instructions)

## Installation

```bash
git clone https://github.com/alializadeee24/Network-Sniffer.git
cd Network-Sniffer
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Usage

```bash
python3 sniffer.py
```
